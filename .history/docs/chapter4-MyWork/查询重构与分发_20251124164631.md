# 查询重构与分发

检索之前对用户查询进行预处理，包括查询重构和查询分发。查询重构旨在将用户查询转化为搜索引擎能够理解的形式，查询分发旨在将用户查询分发到多个索引中，从而提高查询的召回率。

此阶段包含两个关键技术：

1. 查询翻译：将用户的原始问题转换为一个或多个更适合检索的查询形式。
2. 查询路由：根据问题的性质，将其智能地分发大最合适的数据源或检索器。

## 查询翻译

查询翻译旨在弥合用户自然语言提问与文档库存储信息之间的语义鸿沟。可通过重写、分解或扩展查询显著提升检索的准确率

### 1. 提示工程

提示工程（Prompt Engineering）是一种将用户查询转化为搜索引擎能够理解的形式的方法。它通过设计一系列的提示词，引导用户输入更加精确的查询，从而提高检索的准确率。

例如，对于用户查询“苹果手机”，可以通过设计一系列的提示词，如“苹果手机价格”、“苹果手机最新款”、“苹果手机评价”等，引导用户输入更加精确的查询，从而提高检索的准确率。
