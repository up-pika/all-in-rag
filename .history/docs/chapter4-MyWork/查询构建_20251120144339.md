# 查询构建

实际应用中，查询不仅仅是简单的语义匹配，而是包含复杂的过滤条件、聚合操作或关系查询。故需要查询构建技术，利用LLM的强大理解能力，将用户的自然语言查询“翻译”为针对特定数据源的结构化查询语言或带有过滤条件的请求，极大地扩展RAG应对各种类型数据的能力。

## 文本到元数据过滤器

充分利用数据的元数据信息，在语义检索之外提供精确匹配的可能性。

LangChain 的自查询检索器可实现这个功能，工作流程如下：

1. 定义元数据结构
2. 查询解析：将用户的自然语言查询解析为两部分：
   1. 查询字符串：用于语义匹配
   2. 元数据过滤器: 从查询中提取的结构化过滤条件，用于精确匹配
3. 执行查询：检索器将解析出的查询字符串和元数据过滤器发送给向量数据库，执行一次同时包含语义匹配和精确匹配的查询。

## 文本到Cypher

查询构建不仅可以处理扁平化的元数据，还可以处理复杂的关系型数据。例如，在图数据库中，查询构建器需要将自然语言查询翻译为Cypher查询语言。

LangChain 的工具链（如`GraphCypherQAChain`）可以利用LLM 的能力，将自然语言查询翻译为Cypher查询，从而在图数据库中执行复杂的查询。

工作流程如下：
1. 接收自然语言查询
2. LLM 根据预先提供的图谱模式，将自然语言查询翻译为Cypher查询
3. 在图数据库上执行Cypher查询，获取精确的结构化数据
4. （可选）将查询结果再次交给LLM，以生成更自然、更符合用户期望的答案。
   
通过这种文本to Cypher的查询构建方法，用户可以用最自然的方式与高度结构化的图数据进行交互，降低查询的复杂性。
