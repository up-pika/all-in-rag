# 查询重构与分发

检索之前对用户查询进行预处理，包括查询重构和查询分发。查询重构旨在将用户查询转化为搜索引擎能够理解的形式，查询分发旨在将用户查询分发到多个索引中，从而提高查询的召回率。

此阶段包含两个关键技术：

1. 查询翻译：将用户的原始问题转换为一个或多个更适合检索的查询形式。
2. 查询路由：根据问题的性质，将其智能地分发大最合适的数据源或检索器。

## 查询翻译

查询翻译旨在弥合用户自然语言提问与文档库存储信息之间的语义鸿沟。可通过重写、分解或扩展查询显著提升检索的准确率

### 1. 提示工程

提示工程（Prompt Engineering）是一种将用户查询转化为搜索引擎能够理解的形式的方法。它通过设计一系列的提示词，引导用户输入更加精确的查询，从而提高检索的准确率。

例如，对于用户查询“苹果手机”，可以通过设计一系列的提示词，如“苹果手机价格”、“苹果手机最新款”、“苹果手机评价”等，引导用户输入更加精确的查询，从而提高检索的准确率。

例如，采用更高级的提示工程技巧：让LLM直接构建出查询指令。采用这个方法可以解决“时间最短的视频”这类需要排序或比较的查询。

### 2. 多查询分解

多查询分解（Multi-query Decomposition）是一种将用户查询分解为多个子查询的方法。通过将用户查询分解为多个子查询，可以更好地理解用户的意图，从而提高检索的准确率。

例如，对于用户查询“苹果手机价格”，可以将其分解为两个子查询：“苹果手机”和“价格”，从而更好地理解用户的意图。

### 3. 退步提示

退步提示是由 Google DeepMind 团队提出的一种旨在提升大语言模型推理能力的提示工程技巧2。当面对一个细节繁多或过于具体的问题时，模型直接作答（即便是使用思维链）也容易出错。退步提示通过引导模型“退后一步”来解决这个问题。

其核心流程分为两步：

1. 抽象化：引导 LLM 从用户的原始具体问题中，生成一个更高层次、更概括的“退步问题”（Step-back Question）。这个退步问题旨在探寻原始问题背后的通用原理或核心概念。
2. 推理：系统会先获取“退步问题”的答案（例如，一个物理定律、一段历史背景等），然后将这个通用原理作为上下文，再结合原始的具体问题，进行推理并生成最终答案。

### 3. 查询扩展

查询扩展（Query Expansion）是一种通过增加与用户查询相关的词汇来扩展用户查询的方法。通过查询扩展，可以增加检索的召回率，从而提高检索的准确率。
