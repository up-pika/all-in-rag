# 检索进阶

基础RAG流程中，依赖的向量相似度从知识库中检索信息，存在局限性：例如最相关的文档不总在检索结果的最前面，以及语义理解的偏差等。

## 1. 重排序（Re-ranking）

### 1.1 RRF(Reciprocal Rank Fusion)

基于文档在多个不同检索器（例如，一个稀疏检索器和一个密集检索器）结果列表中的排名来计算最终分数。

### 1.2 RankLLM / LLM-based Reranker

RankLLM代表了一类直接使用LLM进行重排的方法。基本逻辑：将检索到的文档作为输入，通过LLM进行重排。例如，使用LLM对检索到的文档进行排序，或者使用LLM对检索到的文档进行打分。
