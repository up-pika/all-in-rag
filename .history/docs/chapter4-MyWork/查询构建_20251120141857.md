# 查询构建

实际应用中，查询不仅仅是简单的语义匹配，而是包含复杂的过滤条件、聚合操作或关系查询。故需要查询构建技术，利用LLM的强大理解能力，将用户的自然语言查询“翻译”为针对特定数据源的结构化查询语言或带有过滤条件的请求，极大地扩展RAG应对各种类型数据的能力。

## 文本到元数据过滤器

充分利用数据的元数据信息，在语义检索之外提供精确匹配的可能性。

LangChain 的自查询检索器可实现这个功能，工作流程如下：

1. 定义元数据结构
2. 查询解析：将用户的自然语言查询解析为两部分：
   1. 查询字符串：用于语义匹配
   2. 元数据过滤器: 从查询中提取的结构化过滤条件，用于精确匹配
3. 执行查询：检索器将解析出的查询字符串和元数据过滤器发送给向量数据库，执行一次同时包含语义匹配和精确匹配的查询。
